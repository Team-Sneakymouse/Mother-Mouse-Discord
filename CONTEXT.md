# Mother Mouse Discord

Domain language for Discord features that coordinate rewards with Legend of Mice 2.

## Language

**Active account**:
A game account eligible for activity-based rewards because it was online during the applicable rolling activity window. Eligibility is independent for each account, including accounts belonging to the same player.
_Avoid_: Active user, online Discord member

**Reward mail**:
In-game mail addressed to a game account that grants its recipient an item or other reward when claimed.
_Avoid_: Discord message, direct message

**Player**:
A person who may own multiple game accounts. Player identity does not collapse account-level reward eligibility.
_Avoid_: Account
